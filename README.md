# 💰 Extrato Bancário em Java

Projeto desenvolvido para praticar estruturas de dados em Java.

## 📌 Funcionalidades

- Leitura de arquivo CSV
- Remoção de transações duplicadas
- Ordenação por data e hora
- Agrupamento por titular
- Cálculo de saldo final

## 🧠 Estruturas utilizadas

- ArrayList
- HashSet
- HashMap

## ▶️ Como executar

1. Baixe o projeto
2. Compile:
   javac Main.java Transacao.java
3. Execute:
   java Main

## 📂 Arquivo de entrada
